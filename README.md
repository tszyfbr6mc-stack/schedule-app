# 학습 시간표 GitHub Pages 배포

이 폴더 안의 파일을 GitHub 저장소에 올리면 핸드폰에서 앱처럼 사용할 수 있습니다.

## 올리는 방법

1. GitHub에서 새 repository를 만듭니다.
2. `schedule-app` 폴더 안의 파일 4개를 repository 최상단에 올립니다.
3. GitHub repository에서 `Settings` > `Pages`로 이동합니다.
4. `Build and deployment`의 `Source`를 `Deploy from a branch`로 선택합니다.
5. `Branch`를 `main`, 폴더를 `/root`로 선택하고 저장합니다.
6. 표시되는 GitHub Pages 주소를 핸드폰 Safari 또는 Chrome에서 엽니다.

## 핸드폰에 앱처럼 추가

iPhone:

1. Safari에서 GitHub Pages 주소를 엽니다.
2. 공유 버튼을 누릅니다.
3. `홈 화면에 추가`를 누릅니다.

Android:

1. Chrome에서 GitHub Pages 주소를 엽니다.
2. 메뉴를 엽니다.
3. `앱 설치` 또는 `홈 화면에 추가`를 누릅니다.

체크 기록은 브라우저의 localStorage에 저장됩니다. 같은 핸드폰의 같은 브라우저에서는 기록이 유지되지만, 다른 기기와 자동 동기화되지는 않습니다.

## 출력용 4주 시간표

`print-4weeks.html`을 열면 A4 한 장에 4주치 시간표를 출력할 수 있습니다. GitHub Pages 주소 뒤에 `/print-4weeks.html`을 붙여서 열면 됩니다.
